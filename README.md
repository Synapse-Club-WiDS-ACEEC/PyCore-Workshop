### 💡 Workshop Overview

The **PyCore Workshop** is a fast-paced, 10-hour hands-on bootcamp designed for 1st and 2nd-year CSD students. Spanning across 2 power-packed days (5 hours/day), this workshop bridges core Python fundamentals with real-world data analytics workflows, moving from foundational data manipulation to an applied hackathon-style dataset sprint.

### 📂 Practice Datasets & Real-World Use Cases

Students work on pre-loaded practice datasets with intentional real-world quality issues (missing values, irregular formatting, duplicate rows) to learn authentic data preparation skills:

* 🏏 **IPL Cricket Analytics:** Player performance metrics, team head-to-head records, and match trends.
* 🎬 **Netflix Titles Analysis:** Content distribution, release patterns, genre categorization, and ratings.
* 🎵 **Spotify Music Trends:** Global audio features, top track metrics, and streaming statistics.
